# 第五版更新说明

更新日期：2026-05-12

本次更新将本地 `E:\pycharm\PINN\第五版\lake_pinn` 整理进仓库，作为当前主线源码。更新包含 Python 源码、说明文档和少量代表性结果图；未提交 checkpoint、预测 CSV、批量热图、完整评分输出或 `__pycache__`。

## 更新内容

- 新增 `第五版/lake_pinn/`，延续第四版模块化包结构。
- 默认输入维度升级到 27 维，支持扩展 forcing、past-only weather memory 和 previous-state memory。
- raw PINN 成为默认预测主线；rolling prediction、Kalman 和 PPO 更明确地作为可选对照或诊断能力。
- 新增 `--disable-kalman`、`--disable-ppo-training`、`--disable-rolling-prediction` 等开关，使实验分支更可控。
- 新增 `seasonal_blocked` profile split 和训练日期抽样参数，用于低数据和季节泛化实验。
- 新增 profile-grid physics、density regularization、bottom slow-change 等训练侧结构约束。
- 升级 `lake_profile_scorecard.py` 到 scorecard v2，增强季节覆盖、失败项统计、候选排序和 PNG 报告能力。
- 第四版已移入 `归档/第四版/`，保留为第五版前的模块化对照。
