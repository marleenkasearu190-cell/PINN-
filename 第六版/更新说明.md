# 第六版更新说明

更新日期：2026-05-15

本次更新将本地第六版 `lake_pinn` 整理进仓库，作为当前多湖与迁移学习主线。更新包含源码、物理扩散测试、实验摘要和少量代表性结果图；未提交 checkpoint、预测 CSV 或完整实验输出目录。

## 更新内容

- 新增 `第六版/lake_pinn/`，承接第五版 raw PINN 主线。
- 新增 `GlobalAdaptiveLakePINN`，支持 global backbone + lake adapter/residual 的多湖联合训练。
- 新增 `multilake_global_adapter.py`，用于多湖 manifest 训练、按湖分组验证和 leave-one-lake 实验。
- 新增 `fewshot_adapter.py`，用于目标湖少量剖面日期的 residual adapter 适配。
- 强化 Kinneret 等 warm/deep lake 的物理约束，包括深层慢变化、Jan deep memory、温跃层形态和密度稳定。
- 修复并验证 Richardson-number-dependent eddy diffusivity 的稳定/不稳定梯度响应。
- 整理本轮代表结果图到 `docs/figures/`，并在 `README.md`、`EXPERIMENTS.md` 和 `第六版/实验总结.md` 中记录最佳实验。

## 实验定位

第六版从单湖 raw PINN 推进到多湖泛化和 few-shot 迁移：

- Kinneret 单湖方向：`T54_Kinneret修复时间步长后T51微调` 达到 RMSE 0.670，MAE 0.443，bias -0.159，物理底线通过。
- Sparkling few-shot 方向：`lakeSpecificResidual_softBound_surfaceUniform_20d` 达到 held-out RMSE 1.402，MAE 1.078，bias 0.340，物理底线通过。
- Leave-one-lake 方向：`LOO_03_train_Mohonk_Sparkling_Erken2019_test_Mendota` 的最佳训练摘要 test RMSE 为 1.079。
- Mohonk 方向：第六版复评和时间步长修复没有超过第五版 T34；当前仍以 T34 离散点 RMSE 1.227 作为 Mohonk 参考。
