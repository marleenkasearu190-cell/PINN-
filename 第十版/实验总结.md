# 第十版实验总结

第十版实验围绕 zero-profile reconstruction-state 展开。核心问题不是追求一个新的长时段最优热图，而是验证：零剖面初始化、daily-memory 分支、无剖面 heat-closure 诊断和 group-kfold split 能否形成可靠的下一轮训练基础。

## 主记录：R42 group-kfold diagnostic

实验名称：

```text
RECON_R42_GROUPKFOLD_V1_fold01-05_6H_SUBMIT
```

设置摘要：

- 5-fold group-kfold smoke/diagnostic。
- 5/5 folds 完成到 epoch 2。
- `full_eval_every_epochs=0`，训练期不做完整 export。
- heldout 指标为 diagnostic-only，不用于 checkpoint selection，不作为 formal transfer claim。
- locked final groups `carvins_cove / lacawac / lake_maggiore` 排除在 R42 fold train/heldout manifests 之外。

## Heat-closure 诊断

R42 中 no-profile heat-closure 有有效 windows，但 loss 仍为 0：

- valid step count 为 `113` 到 `131`。
- residual absolute mean 仅约 `0.0005` 到 `0.0019 W/m2`。
- dead-zone threshold 为 `50 W/m2`。
- 因此当前约束信号过弱，不能证明无剖面 heat-closure 已经发挥训练作用。

这说明下一轮需要调整 heat-closure residual 定义、阈值、gating 或 state source，而不是直接把 R42 当作完整物理约束成功记录。

## 结论

第十版适合作为下一轮 zero-profile 长训和更严格 cross-lake 诊断的工程基础。它的价值在于把零剖面初始化、daily-memory、heat-closure、GPU batch autotune 和 source package hygiene 纳入同一主线；R42 的数值结果只能作为 early diagnostic 证据，不能作为最终跨湖泛化结论。
