# 第十版更新说明

更新日期：2026-06-23

本次更新将本地第十版整理为仓库当前主线 `第十版/`，并将原 `第九版/` 归档到 `归档/第九版/`。第十版定位为 zero-profile reconstruction-state 诊断主线，主要用于验证新的零剖面初始化、daily-memory 分支、无剖面 heat-closure 约束和源码包整理能力。

## 工程更新

- 新增第十版 `lake_pinn/` 源码，保留 reconstruction-state、multi-lake 训练、scorecard 集成、standard input、source package 和 heat-closure 相关模块。
- 新增第十版测试集：`test_gpu_batch_autotune.py`、`test_source_package.py`、`test_target_matrix_cache.py`、`test_zero_profile_init_net.py`。
- 新增脚本：`scripts/export_source_package.py` 和 `scripts/initial_column_eval.py`。
- 清理公开示例中的本机绝对路径，改用 `<local-data>`、`<local-outputs>` 等占位。
- 生成第十版 R42 代表图到 `docs/figures/`，不提交原始 CSV、checkpoint、日志或完整结果目录。

## 模型与诊断更新

- zero-profile 初始化从简单 prior 扩展到 EOF/PCA thermal basis 和 train-supervised init-net correction。
- 新增 daily-memory reconstruction 分支，用于比较逐日低秩剖面记忆与 physics rollout 主线。
- 强化 `init_physics_rollout` 主线和 `model_mainline` 解析，避免隐式分支配置混淆。
- 新增 no-profile heat-closure window 构造和诊断字段，用于后续把无剖面日期纳入物理约束。
- 新增 GPU batch autotune、target matrix cache 和 source package hygiene 相关测试。

## 已知问题

- R42 仅为 epoch 2 diagnostic，不能替代第九版的 reconstruction/few-shot 诊断，也不能替代第八版的长时段跨湖 heldout 结论。
- fold02 的 heldout RMSE 为 `0.884`，明显弱于其他 fold；弱点组为 `crystal_bog / erken / namco / toolik`。
- no-profile heat-closure loss 为 `0.000`，说明当前 residual 与 `50 W/m2` dead-zone threshold 相比过小，下一版需要重新设计阈值、gating 或约束来源。
