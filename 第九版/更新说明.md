# 第九版更新说明

更新日期：2026-06-14

本次更新将本地第九版整理为仓库当前主线 `第九版/`，并将原 `第八版/` 归档到 `归档/第八版/`。第九版延续 reconstruction-state / state-space forecaster，但工作重点从第八版的跨湖 heldout 主结果转为 reconstruction 诊断、support profile 校正和 zero-profile/few-shot 迁移失败归因。

## 工程更新

- 新增 `第九版/lake_pinn/`，包含 state forecaster、state reconstruction、multi-lake training/export、scorecard 集成和诊断逻辑。
- 新增 `第九版/tests/test_*.py`，覆盖 metadata、forcing modes、conditional priors、standard inputs、state forecaster solver、state multilake、pipeline controller 和 reconstruction 诊断准备脚本。
- 新增 `第九版/scripts/`，包含 pipeline controller、literature scout、tiered smoke 生成、R10/R11/R19/R20/R22/R23/R27-R35 诊断和 autopsy 脚本。
- 清理公开脚本中的本地绝对路径，将默认路径改为相对仓库推导或 `<local-pipeline>` 占位。
- 新增第九版代表图到 `docs/figures/`：framework operator flow、R11 export modes RMSE、R11 lake-type bias/RMSE。
- 将第八版移动到 `归档/第八版/`，作为跨湖泛化 R9 warm-column 基线。

## 模型与诊断更新

- 强化 zero-profile reconstruction 初始化和 heldout reconstruction export。
- 增加 support assimilation、sparse observer 和 episodic few-shot 相关参数与诊断导出。
- 对 LSWT observer 做 R19/R20/R22/R23 系列 autopsy，重点检查表层更新是否过深、过强或在不同湖泊类型上失效。
- 增加 1d loop consistency 与 support update effect 诊断，用于区分评估口径问题、support 编码问题和物理推进问题。
- 用 pipeline controller 与 tiered smoke 机制管理实验层级，减少未验证前提下的长 GPU 训练。
