## 文件

| 文件 | 用途 |
|---|---|
| `PPO策略调控_11维主线_20260426.py` | 当前 11 维主线候选，对应本地实验 `11维测试/九` |

| `lake_profile_scorecard.py` | 湖泊温度剖面分层评分脚本 |

## 当前判断

`PPO策略调控_11维主线_20260426.py` 是当前推荐继续研究的版本。它的 RMSE 不是所有实验里最低，但物理形态和季节结构更适合作为 11 维路线主线。

`PPO策略调控_热收支A线_20260428.py` 是有价值的实验方向。A3/A4 说明能量版热收支可以改善部分漂移问题，但预测阶段的秋季翻混和物理底线仍需继续对齐。

## 评分层级

`lake_profile_scorecard.py` 按以下顺序评价模型：

1. 物理底线：冬季逆温、夏季分层、秋季翻混、全年漂移、温跃层结构。
2. 关键季节过程：5 月升温、7 月表层高温、秋季翻混时间、冬季结构。
3. 数值精度：RMSE、MAE、bias、0-3 m 表层 RMSE、温跃层带 RMSE。
4. 稳定性：重跑波动和 train/predict 一致性。
5. 图像观感：热图是否自然，作为最后参考。
