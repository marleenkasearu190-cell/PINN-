# 第七版更新说明

更新日期：2026-05-31

本次更新将本地 `第七版/lake_pinn` 整理进仓库，作为当前主线源码。第七版不再以直接温度函数 `T(z,t)` 为唯一核心，而是切换到 reconstruction-state / state-space forecaster：模型从当前剖面状态、forcing 和湖泊属性预测后续剖面演化。

## 更新内容

- 新增 `第七版/lake_pinn/`，包含 state forecaster、vertical solver、hypsometry、conditional priors、state reconstruction、多湖训练和诊断工具。
- 新增 `第七版/tests/`，覆盖 metadata、forcing mode、conditional priors、state forecaster solver 和 multi-lake training/export 行为。
- 新增 `第七版/scripts/` 和 `CLOUD_GPU_README.md`，用于云端 GPU 打包和 T5 长实验运行。
- 新增 heat-content transition loss、bulk turbulent flux、latent reservoir freezing mode、hard density stability、segment rollout loss 和 rolling horizon evaluation。
- 新增批量化训练/评估选项，包括 transition batch、segment rollout batch、cross-lake batch、full free-roll batch 和 step tensor mode。
- 第六版已移入 `归档/第六版/`，作为 multi-lake / few-shot 归档基线。

## 实验定位

第七版当前公开主结果为：

```text
T5_Mendota2020_bulkFlux_kz15_heat005_200ep_cloud
```

| 口径 | RMSE | MAE | bias | 当前判断 |
|---|---:|---:|---:|---|
| Mendota 2020 heldout transition | 0.331 | - | - | transition 精度接近 T4 |
| Mendota 2020 full free-roll | 1.190 | 0.837 | -0.466 | 第七版长时段 reconstruction 主结果 |
| Mendota 2020 30d free-roll | 1.000 | - | -0.219 | 30 天滚动稳定性明显优于 T4 |

T4 的 heldout transition RMSE 为 0.330，略低于 T5，但 full free-roll RMSE 为 1.529，长时段稳定性不如 T5。因此第七版以 T5 作为主线记录。
