# 第八版更新说明

更新日期：2026-06-06

本次更新将本地第八版实验目录整理为仓库当前主线 `第八版/`，并将原 `第七版/` 归档到 `归档/第七版/`。第八版继续沿用 reconstruction-state / state-space forecaster，但目标从单湖或少量湖泊验证进一步转向跨湖泛化和整湖 heldout 稳定性。

## 工程更新

- 新增 `第八版/lake_pinn/`，包含状态推进模型、多湖训练、标准输入、scorecard、诊断、导出和绘图模块。
- 新增 `第八版/tests/test_*.py`，覆盖 metadata、forcing modes、conditional priors、standard inputs、state forecaster solver 和 multi-lake 行为。
- 新增 `第八版/scripts/`，包含 lake inventory、cloud manifest、v8 global generalization 输入准备和云端运行脚本。
- 新增 `第八版/benchmarks/pgdl_wrr_compare.py`，用于构建 PGDL-WRR 2019 Mendota benchmark 对照。
- 修正公开代码中的本地绝对路径示例，避免个人机器路径进入仓库文档和默认配置。
- 更新 `.gitignore`，防止 `experiments/`、`external/`、`_archive/`、CSV、checkpoint、日志、缓存和测试烟测输出误提交。

## 模型更新

- 扩展 lake metadata 和条件先验，支持更广泛的 lake-year 输入。
- 加入 temporal adaptive 机制，使部分自适应参数随时间和状态变化。
- 加入 LST dropout 与 segment LST weak loss，降低模型对卫星 LST 的硬依赖。
- 强化 surface/ice latent reservoir 和 warm-column heat-content loss，处理暖季水柱热含量和结冰/表层热滞留问题。
- 采用 roll60 训练约束和 export25 公开导出口径，强调长时段滚动稳定性和统一评估范围。

## 实验定位

第八版公开主结果采用：

```text
R9_WARMCOL_LST_SURFICE_ALL38_holdout3_120ep_roll60_export25_20260605
epoch0099
```

| Lake-year | RMSE | bias | 说明 |
|---|---:|---:|---|
| `lacawac_2016` | 2.405 | -0.244 | 三湖 heldout 中最稳 |
| `carvins_cove_2022` | 5.456 | -4.047 | 冷偏仍明显 |
| `lake_maggiore_2024` | 3.708 | -2.191 | 相比 R7 改善 |
| 三湖平均 | 3.856 | 2.161 absolute bias | 优于 R7 的 4.158 / 2.455 |

R9 没有跑满原计划 120 epoch，训练在 epoch100 后停止；公开结果采用最后可用的 `epoch0099` checkpoint/export。该限制已在实验总结中说明。
